Télécharger l'installeur FlashDev ↓

Setup Windows (.exe) — installe FlashDev. Si LÖVE ou VS Code sont déjà présents, ils sont réutilisés ; sinon installation via winget. Les mises à jour du logiciel se font ensuite dans le menu Options.

Ce que fait FlashDev

  • → Cartes flash = défis de code (Lua, C++ via VS Code)
  • → Répétition espacée SM2 intégrée
  • → Installation de decks premium (GameDevReady)
  • → Liens vers guides web depuis chaque carte

Prérequis Windows

  • → Windows 10 ou 11 (64 bits)
  • → L'installeur configure LÖVE 11.x et VS Code (via winget)
  • → Connexion Internet pour le premier setup
  • → Decks C++ : Raylib dans C:\raylib\ (bootcamp, étape séparée)
